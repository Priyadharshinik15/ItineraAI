# タミルナードゥ旅行ガイド
## 旅行概要
タミルナードゥはインド南部の州で、豊かな文化と美しい風景で知られています。旅行者は、歴史的な寺院、美しいビーチ、活気ある都市を楽しむことができます。

タミルナードゥは、美味しい南インド料理で知られています。以下のスポットは、食い倒れの旅にぴったりです。
* **マサラ・ドサ**: タミルナードゥの伝統的な料理で、薄いパンにスパイスと野菜を詰めたものです。
* **イディリー**: 南インドの伝統的な朝食で、米粉と黒グラム豆から作られた蒸し料理です。
* **ウォンタン・スープ**: タミルナードゥの特色あるスープで、ワンタンとスパイスを入れて作ります。
